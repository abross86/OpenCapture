OpenCapture User Manual

OpenCapture shows, records and photographs video from USB capture cards, webcams and any other video source your Mac recognises. On first launch the first available video and audio inputs are selected automatically; change them in OpenCapture › Preferences… (⌘,).

Preferences

Video source / Video input & format
Choose the device and, optionally, one of its stream formats (size, pixel format, frame rate). "Automatic" picks the best match for the size and frame rate below.
Video size / frame rate
Leave empty for the maximum the device supports.
Video buffer size
"None" drops late frames for the lowest latency; larger settings keep more frames queued.
Video transformation
Flip or rotate the picture; applies to the live view and to recordings. "Live video horizontal flip" mirrors only the live view.
Audio source / format / channels
Pick the input, 16/24-bit at 44.1/48 kHz, and which input channels become the left and right channels of the recording.
Audio delay for movies
Positive values move the audio later, negative earlier (milliseconds).
Image adjustments
Brightness, contrast, Cb (blue/yellow) and Cr (red/green) colour, sharpness. Set Cb and Cr to the same value to change overall saturation.
File name format
Use +Y +y +M +D +h +m +s for year, 2-digit year, month, day, hour, minute, second.
Capture destination
Ask every time, or save automatically to a folder (Desktop by default).
Text overlay
Text drawn at the top-left of every frame (live and recorded); the same date/time tokens apply.
Video / audio encoding
H.264 and H.265 give the smallest files (MP4 with AAC). JPEG and ProRes are intermediate formats saved as MOV. Stop-motion movies never use H.264/H.265 so that frames stay independent.

Image capture

File › Save Image (⌘S) saves the current frame. Edit › Copy (⌘C) puts it on the clipboard. You can also drag the picture out of the window into the Finder or another application.

Video capture

File › Start Recording… (⌘R) starts a movie; the status bar at the bottom of the window shows the duration, frame rate and file size. Choose the same item again to stop. Start Time-Limited Recording… stops automatically after the chosen duration.

Timelapse capture

Captures the configured number of frames every interval and writes them at the playback rate, so slow events play back fast. Continue Timelapse Recording… appends to an existing movie.

Stop-motion capture

The Stop-Motion window shows your movie as it is built. Press Return (in either window) to add a frame from the live video. Onion skin (O) overlays the live picture on the selected frame at 50% so you can line up the next shot. Space plays the movie; the scrubber jumps to any frame; Delete removes the selected frame; Edit › Undo reverts captures. Frame averaging (Preferences) averages several video frames per capture to remove sensor noise — keep the scene still while it runs. Export Stop-Motion Still Image Files… writes every frame as an image.

Audio

Window › Audio shows level meters. Audio › Monitor Audio Through Speakers plays the captured sound on the Mac's output.

Keyboard & window

Double-click the picture for full screen. The Video menu toggles float-on-top and the title bar, and nudges the window with ⌥⌘+arrow keys.

AppleScript

Open OpenCapture's dictionary in Script Editor. Example:

tell application "OpenCapture"
    start capture to file "/Users/me/Desktop/clip.mp4"
    delay 10
    stop capture
end tell

Help

If a device does not appear: check System Settings › Privacy & Security › Camera and Microphone, unplug and reconnect the device, and look at Window › Log (also saved to ~/Library/Logs/OpenCapture.log).
